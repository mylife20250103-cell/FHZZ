# 发票合并系统 V1.1 应用说明书

面向新同事培训。按本说明操作即可完成日常询价、合并发票、改渠道和敏感词检查。

## 1. 使用前准备

- 电脑为 Windows，已安装 **Microsoft Excel**。
- 已登录公司 OneDrive，并能打开：
  `I:\OneDrive\OneDrive - Lion\【采购仓储】\【发货单】\【发票合并】\发票系统`
- 双击 `发票合并系统_V1.1.15.exe` 启动。左侧应显示版本 **v1.1.15**。不要再用 V1.1.14 及更早的 exe。
- 不要用 Excel 打开快越达刚合并好的 `.xls` 再保存，否则上传会失败。

## 2. 整体流程（先记住这一条）

询价中心 → 发票中心（扫描到内容合并，再打开货代后台登录下单）→ 如需改渠道再进「批量修改单元格值」→ 需要时做敏感词检查。  
查看 FBA / Tracking 进「发货追踪」。盯某店某个产品（例如美8 盖片）进「重点追踪」。新增仓库地址时，进「维护」打开「各物流地址库」，不要改官方发票模板。

合并完成后再改渠道。改「全部发票汇总」里的源发票，**不会**改到「合并结果」里已经生成的文件。

## 3. 询价中心

用途：扫描询价明细，生成物流询价汇总表。

日常：

1. 「从 / 到」默认都是今天。要把昨天和今天合成一单，把「从」改成昨天。页面上的 **输出 DateID** 始终是今天，汇总表也写到今天。
2. 可点 **询价路径** 打开目录核对文件：只选一天时打开当天文件夹，跨天时打开「询价路径」根目录。
3. 点 **扫描询价明细**。
4. 检查表格无误后，按页面提示生成询价汇总。

补扫其它目录（漏扫、补文件、不在日期文件夹里的路径）：

1. 点 **＋ 临时追加目录**，选要补的文件夹（对话框默认打开「询价路径」）。
2. 点 **扫描临时追加目录**。这条只会扫你刚选的目录，不会把当天默认目录混进来。

## 4. 发票中心

用途：按批次把物流商发票合并成可上传文件。步骤条为：

① 原始扫描 → ② 快速合并 → ③ 二次扫描 → ④ MergePlan → ⑤ 内容合并 → ⑥ 结果检查 → ⑦ 完成

日常：

1. 「从 / 到」选扫描范围，默认今天。跨天时把「从」改成昨天。批次号和合并结果目录始终写到今天。
2. 点 **开始原始扫描**（只扫当前物流商配置的扫描源，再按日期范围过滤）。
3. 按页面主按钮往下走。准备合并会连续做 ②③④；确认后再点 **开始内容合并**。
4. 合并结果在：
   `发票系统\合并结果\日期\批次号\`
   - 快越达：`KYD_仓库_箱数箱.xls`（同一仓库合成一份，例如 `KYD_PSP3_10箱.xls`）
   - 迈创：`MC_仓库_箱数箱.xlsx`

5. 合并完成后，在本页 **4 货代下单** 选货代和下单账号，点 **打开下单后台**。会用系统默认浏览器打开该货代登录页。请自己登录并上传「合并结果」里的文件。程序不会自动登录，也不会自动下单。迈创多家账号共用同一网站，打开后请登录刚才选的那个账号。

补扫其它目录：

1. 点 **＋ 临时追加目录**（默认打开「物流商发票」）。
2. 点 **扫描临时追加目录**。不要和「开始原始扫描」搞混。

注意：

- 快越达合并结果必须是 `.xls`。不要用 Excel 打开后保存。
- 迈创合并结果是 `.xlsx`，B2 渠道用模板自带名称。
- 内容合并失败时，弹窗可点 **打开自检报告**，按文件看缺字段、海关编码、图片网址等问题。

## 5. 发货追踪

用途：按店铺 / 月份（或日期范围）扫描装箱明细，查看 FBA、SKU、数量，并从货代拉取 Tracking。

日常：

1. 店铺可选某一店，或 **全部店铺**。
2. 月份选具体月份，或选 **其他** 再填日期范围。全部店铺不要选「全部月份」。
3. 点 **扫描发货规划**。
4. 用 **FBA**（或 SKU / 产品中文品名 / 运单号）筛选表格。
5. 点 **从货代拉取**，会查当前筛选结果里的全部 FBA，并填写 Tracking 和「最新物流信息」（路由里时间最新的一条）。已有 Tracking 时，点击蓝色运单号可看详情。
6. 选中一行可点 **加入重点追踪**，之后到「重点追踪」查看。

表格列顺序：候选货代后面是 SKU / 数量 / 产品中文品名，再是 FBA，方便截图给货代。

注意：

- 确认货代来自发票扫描后的 CarrierCode；没有确认时按文件名候选货代查询。
- 货代密钥在 OneDrive `发票系统\公共配置\forwarder_api.ini`，不要拷进安装包。
- 拉取 Tracking 需要能访问快越达 / 迈创 / 皓鹏 / 利合网关。

## 6. 重点追踪

用途：盯某店某个产品最近 60 天的运输情况，不必每次在发货追踪里重筛。

日常：

1. 选店铺，品名填包含关键字（例如「盖片」），可选再填 SKU，点 **加入重点**。
2. 进入本页会自动扫描最近 60 天，按店铺 → 品名 → 发货日期（从早到晚）排列。
3. 默认不显示已签收；给货代对账时勾选 **含已签收**。
4. 点 **刷新物流** 只查这些 FBA 的 Tracking。

清单保存在 OneDrive `发票系统\发货追踪\watchlist.json`，换电脑也能看到同一份重点。

## 7. 批量修改单元格值（改发货渠道）

用途：合并完成之后，批量改渠道单元格。

正确做法：

1. 点 **选择文件夹**，进入当天「合并结果」批次目录，例如：
   `发票系统\合并结果\20260820\20260820-B0012`
2. 表里应出现 `KYD_IND9_1箱.xls` 这种名字，而不是 `IND9_FBA..._快越达发票.xlsx`。
3. 快越达目标单元格一般是 **B4**。填写新渠道后勾选文件，点 **批量执行**。
4. 用鼠标悬停文件名可看到完整路径，确认是「合并结果」再执行。

如果勾选的是源发票（带「快越达发票.xlsx」），程序会提醒：改这些不会更新合并结果。请取消，改选 `.xls` 箱文件。

## 8. 敏感词检查

用途：检查产品英文/中文品名、材质是否命中物流敏感词。

1. 选择要检查的文件或文件夹。
2. 点 **开始检查**。命中后可打开定位，或按规则改单元格后再导出。

写入前请先关闭 Excel 里已打开的同一文件。

## 9. 维护（各物流地址库）

用途：打开需要人工维护的中央文件，方便找到路径。

1. 左侧进 **维护**，或首页点「进入维护」。
2. 「各物流地址库」旁点 **打开文件**。路径为：
   `I:\OneDrive\OneDrive - Lion\【采购仓储】\【发货单】\发货单各源抓取\各物流地址库.xlsx`
3. 快越达改「快越达地址库」，迈创改「迈创地址库」。新增仓库只改这份表。
4. **不要**改 `发票系统\模板` 里官方模板自带的「地址库」工作表。合并时程序会按这份中央表写入。

## 10. 常见问题

**Q：批量修改显示成功，但合并结果里的 B4 没变？**  
A：多半改到了「全部发票汇总」里的源发票。请重新选择「合并结果」里的 `KYD_仓库_N箱.xls`。

**Q：快越达上传报请求错误 / 图片无法识别？**  
A：文件被 Excel 另存过。请重新内容合并，不要用 Excel 打开 `.xls` 再保存。改渠道请用本系统的批量修改。

**Q：快越达上传报「图片不能为空」，同批次其它仓库却正常？**  
A：V1.1.8 及更早在超过 8 箱时会把模板「总申报」共享公式写坏。请用 **V1.1.15** 重新内容合并，上传 `KYD_仓库_N箱.xls`（可以是 10 箱一份）。不要用 Excel 打开后保存。

**Q：内容合并失败，怎么知道是哪几张发票有问题？**  
A：失败时程序会逐张检查源发票，弹窗点 **打开自检报告**。报告在批次目录 `content_merge_diagnose.txt`，会写出箱号、缺字段、海关编码、图片网址、地址库等问题。先改源发票再重新内容合并。

**Q：迈创导入提示找不到服务？**  
A：不要把源发票里的旧渠道名写进模板 B2。V1.1 合并已保留模板自带渠道名。

**Q：其它电脑打不开业务目录？**  
A：确认该电脑已映射同一 OneDrive 路径到 `I:\`，并能打开「发票系统」文件夹。发货追踪还需要能打开「装箱明细」。本程序不把发票文件打进安装包。货代密钥在 `发票系统\公共配置\forwarder_api.ini`，换电脑不必再配。

**Q：日志在哪？**  
A：exe 同目录下的 `logs\app.log`。

**Q：合并报地址库没有某个仓库？**  
A：到「维护」打开「各物流地址库」，在对应物流商工作表补上该仓编码后再合并。不要去改官方发票模板。

**Q：点「打开下单后台」会自动登录或自动下单吗？**  
A：不会。只打开该货代的登录网页。Token 只用于发货追踪查轨迹，不会写进浏览器。迈创多家账号打开的是同一个网站，请在网页里登录所选账号。

**Q：找不到询价明细文件夹？**  
A：在询价中心确认「从 / 到」日期范围，点 **询价路径**。单天打开当天目录；跨天打开询价路径根目录。目录还不存在时，程序会提示完整路径。
