# 皓鹏货件数据核对

用户已确认规则并授权仅修改相关代码、提交Git和发版。沿用独立核对页，直接粘贴皓鹏原文；不增加旧合并器货代，不修改报关、渠道写入、追踪或中央业务文件。

采用专用HP解析及只读模板适配；不要求人工把消息转换为MC格式，不更改现有MC/KYD协议。HPT数字订单启动一个消息块，跨行读取FBA、皓鹏后的完整渠道、报关方式前的渠道边界及“收费重”数值。票内重复FBA去重，保留原文；跨票重复、无效重量或缺字段仍报异常。

HP官方.xls模板“单票下单-填写表”：B1渠道、B2完整仓库地址编码、B14箱数；第18行表头、第19行起A完整箱号、G实重、H/I/J长宽高。按真实结构识别外部成品文件，原件只读；可接受非标准文件名，仍检查真实格式、标签、表头、箱数、同箱冲突。MC/KYD读取及文件名约束不变。

同货代完整FBA集合优先，HP允许全部已列FBA唯一指向同一份发票时辅助关联，按全部货箱核算；多候选、同文件多报数、跨文件重复等原阻断继续适用。整票核准上限=MAX(21, CEILING(MAX(实重合计, 每箱(长+2)(宽+2)(高+2)/6000合计))) kg。21kg仅用于HP；不改变MC/KYD。原预估值继续表示仓库原始取大值，核准上限包含最低计费重。

界面及导出注明HP最低21kg与支持跨行原文；现有列、红色重测标签、明细和原文留档保留。仅确认重量和现有渠道字符串差异，不自动确认货代通知中的地址或发消息。V1.1.24打包保留构建PATH隔离，记录真实验证及未验收项；dev、标签、GitHub和公司新版本目录均在本次授权内。
