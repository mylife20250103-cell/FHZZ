## 已确定业务

- 官方服务目录通过现有物流账号的只读查询接口获取；内部渠道分类由人员补充。
- 精确匹配物流商、实际目的国、目的仓库、内部渠道、税费方式、派送方式。
- 税费选项为包税、递延（不包税）；这是内部分类，保留官方服务原始代码和名称。
- 派送选项为卡派、快递派。没有规则或多条不同规则时不得默认选择。
- MC 模板!B2、KYD 模板!B4、HP 单票下单-填写表!B1；保留人工覆盖，验证服务标签、真实模板及目标格。
- 每份文件独立生成服务建议；条件和建议可逐行调整，人工勾选确认。
- 完整批次另存，原件不动，文件名保留，记录外置。不得把报关修订目录中的修改记录当作上传发票。

## 数据与接口

2026-10-23 已只读访问四个配置网关的 /api/v5/docs，以及迈创 /api/v5/docs/markdown 第11节。
正式目录接口 POST /api/v5/shipment/get_services，报文 {"services":{"type":"all"}}，成功 status=1、data.services 数组，含 code/name/type 等。不使用下单、计费或修改运单接口。
文档未提供内部分类及服务到目的仓库的覆盖关系，须人工规则明确指定；不推断全仓覆盖。
目录按 provider_id 隔离，缓存仅保存白名单服务字段及时间，不保存 Token。单账号失败保留上次成功目录并显示警告；成功空目录视为真实空目录。
人工规则 Excel 单独维护，目录更新不覆盖规则。一个规则必须指定账号、服务代码、准确填写文本和完整匹配条件。

复用既有报关模块的局部 XML/BIFF 补丁原语及非目标内容验证，不改变其产品替换业务。

## 安全与验收

识别依据模板结构、仓库字段和中央地址库，文件名不作身份依据。拒绝源元数据发票、混货代、混国、符号链接/目录联接和公式目标。
扫描锁定规则、目录、文件清单及内容哈希。确认时重新校验，变化需重扫。
在输出根目录创建唯一暂存目录，全部写入及回读成功后改名发布；失败不发布完整结果，原件始终不改。
XLSX 保留非目标 ZIP 内容；XLS 保留非目标 OLE 流、BIFF 语义、图片和公式，不经 Excel 另存。
相关测试及完整回归使用 D 盘临时目录。真实 API 仅验证目录读取；实际货代上传须业务验收。
