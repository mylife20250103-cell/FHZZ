# 货件数据核对独立页面与重点标记

用户要求：把原发票中心第5块迁移为独立模块，侧栏顺序为发票中心→货件数据核对→发票报关修改；结果表列间有分隔线，需申请重测有明显重点标记。

采用复用现有ReconciliationPanel的独立ReconciliationPage，不复制第二份核对状态。MainWindow持有页面并连接原发票合并成功信号，隐藏时也接收目录；切换页面不重建页面。任务关闭保护迁移到MainWindow的新页面检查。发票中心移除原第5块，顶部七阶段保留。

表格局部启用清晰实线网格和表头列分隔，不改其他模块全局样式。需重测状态使用红底白字加粗标签，超限差额红字加粗，选中行时标签保持醒目。重绘/筛选不得残留旧标签，标签不阻断选择及双击货箱明细。

优先沿用已有浅色主题和线性导航图标，不增加依赖。核对、部分FBA关联、整票重量及导出语义不变。此次为源码优化，未授权新一轮提交/发版。
