# 迈创部分 FBA 辅助关联

用户已确认：迈创可能只列3个FBA，但计费重量覆盖该票全部货箱，要求采用部分FBA辅助关联。此口径取代上一轮“必须补齐才能匹配”的限制。

## 方式与约束

保持完整集合优先；完整集合找不到时，迈创报数的非空FBA集合必须全部包含于唯一同货代发票。不限FBA顺序或仅发票前三个，不按重量或消息次序猜测。完整集合与部分集合统一执行原有重复、跨源FBA交叠、异常源数据和报数异常拦截。多条报数指向同一文件时不拆票或分摊重量。

通过唯一性和异常检查后，使用该文件全部货箱的实重/公差体积重合计取大，再整票向上进位1kg。辅助关联不按已列FBA截取箱子，不能将部分相交误当成所有已列FBA均包含。

结果保持原重量状态及重测筛选，并显示“关联方式”“报数未列FBA”。所含FBA、箱数和箱级明细均来自完整发票；原文保留原始报数，不自动补写或改写货代原文。Excel导出同样保留这些信息。
