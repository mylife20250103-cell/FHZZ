# V1.1.25 迈创四列报数兼容

日期为 2026-11-23（Asia/Shanghai）。用户授权提交 Git 并发布此版本。

## 本版内容

迈创报数支持两种方式。原括号格式和空格或制表符分隔的四列格式均可直接粘贴，每票一行，多个FBA用逗号分隔。程序按订单开头识别货代并调用对应规则，`MC` 为迈创，`HPT` 为皓鹏。异常行中可读的FBA参与重复检查，避免错误报数通过核准。

V1.1.23和V1.1.24均能复现四列报数失败。11月20日批次的12份发票、15箱均可读取，异常产生在报数解析环节。本次更新覆盖核对解析、界面提示、相关测试、版本和发版说明。

## 验证

在离屏核对面板读取 `20261120-B0001`，复核截图可见的6条报数。6票均按完整FBA匹配，重量均在允许范围，AVP1的33kg报数等于核准上限。其余6条未出现在截图中，未逐票核对。原11月4日迈创括号报数17票中仍有6票辅助关联、2票各超1kg。皓鹏的原文解析与21kg边界由核对回归覆盖。

全量回归433项通过、1项失败、2项警告（35.44秒）。失败为已知的 `tests/test_customs_service.py::test_uploaded_kyd_batch_can_publish_complete_revision_to_test_directory`，历史快越达样本未命中当前报关规则。

PyInstaller 构建成功。已实际启动最终 EXE 并进入主界面，确认版本和核对入口。原生点击受工具限制，随后用从最终 EXE 提取的 UI 和业务代码离屏复核迈创两个真实批次、皓鹏官方模板副本及筛选和导出。两批迈创源文件和皓鹏模板哈希一致。
