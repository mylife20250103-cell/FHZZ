# V1.1.24 皓鹏货件数据核对

日期：2026-11-19（Asia/Shanghai）。用户已确认规则并授权仅修改相关代码、提交Git和打包发版。

## 本版内容

独立货件核对页支持皓鹏HPT订单跨行原文，自动去除同票重复FBA，提取皓鹏后完整渠道及“收费重”数字；客户前缀、报关方式与通知不混入渠道。完整FBA集合优先，唯一部分FBA辅助关联按该票全部货箱核算。皓鹏核准上限=MAX(21, 整票实重合计与每箱公差体积重合计取大后向上取整到1kg)，每边公差2cm、除数6000；21kg下限仅用于HP。

只读官方.xls“单票下单-填写表”：B1渠道、B2完整仓库编码、B14箱数，第18行表头、第19行起A/G/H/I/J箱号/实重/长宽高。支持按真实专用工作表识别非标准文件名；完整箱号去重并校验箱数、表头及量尺。错误格式保留可读FBA，坏量尺保留箱身份参与跨文件冲突，未知损坏xls不阻塞正常文件扫描。跨单重复、多文件归属和一文件多报数继续阻断。

改动仅涉及核对服务、核对面板提示、相关测试、版本/spec名称与维护发布文档。未改旧发票合并器、报关、渠道写入、追踪或中央业务文件。沿用原构建PATH隔离，保留旧版本历史。
