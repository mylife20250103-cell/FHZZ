# V1.1.21 启动修复

日期：2026-11-17（Asia/Shanghai）。

## 问题与修复

V1.1.20 发布包双击启动时在 `main.py:3` 导入 QtGui 失败，提示“找不到指定的程序”。这是打包依赖问题。构建宿主 PATH 中的 Poppler 提供另一套同名 `icuuc.dll`，PyInstaller 收集后放在程序包根目录；其 `_78` 后缀导出接口不能满足 Qt6Core 对 Windows ICU 无后缀接口的依赖。

在原包解出的本机副本中，Qt6Core 加载复现 WinError 127；仅移除错误 ICU 后，Qt6Core、Qt6Gui、Qt6Widgets 全部加载成功。此实验没有修改已发布 exe、Windows 系统文件或 Python 环境。

修复将 spec 的构建 PATH 限定为当前 Python 和 Windows 系统目录，各包所需 DLL 继续由 hook 收集。新包不含构建宿主工具目录文件或 ICU DLL，Windows ICU 由操作系统提供。版本升为 V1.1.21，保留 V1.1.20 历史记录。
